Softroniics Learning Management System
Project Overview

The Softroniics Learning Management System is a centralized platform created to facilitate seamless knowledge sharing, course enrollments, module quizzes, and attendance logging for technical training bootcamps.

Key Features
  • Interactive video player with auto module completion detection.
  • Role-based user management (Admin, Instructor, and Student portals).
  • Live analytics dashboard displaying student progress percentages and quiz milestones.
  • Downloadable lecture notes and automated certificate generation.
Technologies Used
Python Bootstrap 5 JavaScript SQLite HTML5 / CSS3

AutoResq - Mechanic Assistance App
Project Overview

AutoResq solves roadside vehicle emergencies by connecting stranded motorists with the nearest available certified mechanics, tire shops, and towing vehicles through live geotracking.

Key Features
  • One-tap Emergency SOS dispatch with automatic GPS location broadcast.
  • Real-time mechanic map tracking with estimated time of arrival (ETA).
  • Categorized service requests (Battery jump, Flat tire, Fuel delivery, Towing).
  • In-app direct emergency calling and instant messaging.
Technologies Used
Flutter Dart Firebase Auth & Firestore Google Maps API
Visit GitHub Repo
Blessing - Islamic Tracker App
Project Overview

Blessing is an all-in-one daily spiritual companion application designed with a serene, modern dark UI to help users track prayers, read daily Quranic verses, and find the Qibla direction smoothly.

Key Features
  • Dynamic prayer times calculation based on GPS latitude and longitude.
  • Animated live Qibla compass using device magnetometer sensor.
  • Daily Quran verse of the day with Arabic calligraphy, translation, and audio.
  • Customizable Adhan audio reminders and offline SQLite prayer logs.
Technologies Used
Flutter Dart SQLite Local DB Device Sensors API Local Notifications
